# Little Screens

Send messages and GIFs to a paired pair of little OLED clocks.

Static page, no build step, no external requests except the MQTT broker you
pair it with. Everything sent is end-to-end encrypted (AES-256-GCM) with a
key that lives only in your pairing code, your browser, and the two clocks.

Published from `web/` of the (private) firmware repo.
